# My Chat Faces 1.3.9

Prepared September 29, 2026.

## Visibility fixes

- Recognize ChatGPT's current user bubbles and assistant markdown, alongside the earlier message-role layout. Stop assigning roles by alternating conversation indexes.
- Recognize current Grok user and assistant messages on grok.com and X's separate React Native Web layout. Keep separate user and assistant surfaces in Gemini and avoid nested bubbles in Claude.
- Clear backgrounds only on ancestors of recognized chat surfaces. Native cards, controls, and embedded app previews no longer lose their backgrounds because of generic CSS utility classes.
- Apply text size through nested response content. Preserve code indentation, horizontal code scrolling, and heading hierarchy.
- Theme composers, navigation, menus, dialogs, Canvas and Artifact containers with matched text and background colors. Keep large-text inputs within narrow panels.
- Reconcile markers when sites stream responses, reuse message nodes, or change attributes. Turn styling off when leaving Grok's X route.
- Handle missing or null stored styles without crashing. The Balanced preset and Apply Style now work on first use even when their values match the defaults.
- Use independently guarded colors in code and toolbar previews.
- Correct the X background-resource match pattern. Chrome requires web-accessible resource patterns to end in `/*`; the content script remains scoped to `/i/grok*`. See the [Chrome manifest documentation](https://developer.chrome.com/docs/extensions/reference/manifest/web-accessible-resources).

## Verification

- Live DOM inspection: ChatGPT, Claude, Gemini, Grok, and X/Grok, including short synthetic Claude and X/Grok responses. No private conversation contents are included in test fixtures.
- Browser regression suite: **65/65 scenarios passed, 2,015 checks, zero failures**. Current and legacy ChatGPT and Claude, Gemini, Grok, and current and semantic-marker X/Grok fixtures; four color/text configurations at 390px and 1000px widths. Tests cover contrast, message detection, single bubbles, text sizing, code formatting, narrow layouts, menus, document panels, dynamic updates, Apply Style, null settings, removal, and X route exit.
- Popup checks: first-use Balanced, every accessibility preset, manual sizing, Apply Style, and Remove Background.
- Independent compositing checks cover 14,336 surface/text/backdrop combinations, plus invalid settings and preservation of safe colors.
- Release builder checks syntax, manifest constraints, asset references, contrast, ZIP integrity, and the packaged manifest. A SHA-256 file accompanies the ZIP.

## Scope and final manual check

Browser regressions use the production scripts and CSS with simulated Chrome storage and sanitized markup. They do not prove every live account, experiment, or future site layout. Chrome's extension-management page is blocked by the browser automation policy in this session, so the new build has not been reloaded and exercised as an installed extension on the live sites. The X adapter uses observed class signatures because that view lacks semantic message markers; changes to those signatures will need another compatibility update.

Before submitting to the store, load the unpacked `my-chat-faces-v1.3.9` staging directory in Chrome, reload each supported chat tab, and check Paper, Low Vision, a custom background, a new streamed answer, and an opened document panel. Use only one enabled My Chat Faces installation during that check.

Cross-origin/sandboxed Artifact apps, embedded websites, and browser PDF viewers keep their native contents. The extension themes the surrounding panel without requesting access to those separate origins. Background removal preserves saved style settings, as described in the popup.
