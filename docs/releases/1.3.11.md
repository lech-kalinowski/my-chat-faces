# My Chat Faces 1.3.11

Prepared November 24, 2026. ChatGPT workspace compatibility hotfix.

## Diagnosis

Read-only inspection of the affected live ChatGPT tab confirmed that the wallpaper was loaded and visible in the navigation rail. An opaque `rgb(14, 14, 14)` `::before` layer on `[data-app-shell-workspace]` covered the main page. The October fix targeted `[data-app-shell-workspace-row]`, whose pseudo-element is no longer painted in this layout.

The home greeting also moved out of `.home-composer-anchor`. It now uses a `group/home-composer-layout` wrapper and headings containing `data-headline`, including an invisible measurement copy and an animated visible copy.

## Changes

- Clear the backdrop on either known workspace container, only on ChatGPT, only while a background is active, and only when the container is a marked chat ancestor. Native unrelated backgrounds and pseudo-elements remain untouched.
- Protect the updated home greeting with a readable surface. Preserve the invisible measurement heading and constrain both copies to the available width.
- Observe late-added headline markers so streamed greetings receive the same protection.
- Retain the October popup status-handshake fix and existing provider selectors. No new permissions or wider site access.
- Add sanitized November conversation and home-screen fixtures alongside the October and legacy layouts, including the desktop-only workspace pseudo-element.

Fixtures run production CSS and JavaScript with simulated Chrome APIs; they do not establish installed-extension end-to-end compatibility.
