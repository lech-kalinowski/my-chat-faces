# My Chat Faces 1.3.10

Prepared October 1, 2026. ChatGPT background hotfix.

## Root causes

- Live inspection of the affected ChatGPT layout found an opaque `::before` backdrop on `[data-app-shell-workspace-row]`. The wallpaper loaded correctly, and the ancestor backgrounds were transparent, but this separate decorative layer still covered the image. The fix clears only this ChatGPT backdrop while a background is active; removing the wallpaper restores the native layer.
- The popup inferred support from `tabs.Tab.url`. The extension has only the `storage` permission, so that sensitive property can be absent. A content-script status handshake now confirms the supported site without new permissions. A missing receiver produces refresh guidance, not a false unsupported-site warning.
- ChatGPT home-screen headings and suggestion rows now have guarded reading surfaces when styling is active. Message selectors and provider-specific layouts for Claude, Gemini, and Grok are unchanged.

## Testing gap corrected

The 1.3.9 suite used simplified shell markup and a solid background. It did not include the opaque workspace pseudo-element, actual image decoding, uploaded-image switching, the empty ChatGPT home screen, or a popup tab whose URL is unavailable. Passing that suite did not establish that custom wallpapers worked in the installed build.

The expanded browser suite covers all three built-in images and a locally generated uploaded PNG, four text/color configurations, desktop and narrow layouts, custom-to-solid switching, background removal, preservation of native decorations, custom upload optimization/reselection in the popup, and connected/disconnected popup messaging. Existing provider fixtures remain in the suite as regression checks.

The previous staged 1.3.9 package can be tested against the same cases with `http://127.0.0.1:8787/?baseline=1.3.9`. The normal URL runs the working-tree scripts.

## Verification results

- Staged 1.3.9 baseline: 56/73 scenarios passed, 17 failures. All 16 current/home ChatGPT image-background scenarios reproduced the opaque-backdrop bug; the popup test reproduced the missing-URL warning.
- Patched build: 73/73 scenarios passed, 2,429 checks, zero failures. This includes the unchanged provider fixtures and the new uploaded-image/popup cases.
- Node contrast suite: 4/4 tests passed, including 14,336 independent compositing combinations.
- JavaScript syntax, whitespace checks, release manifest validation, and ZIP integrity checks passed. Packaged runtime files match the tested source files.
- The landing-page release copy and store description are updated locally. No store submission or website deployment was performed in this task.

## Release gate

Browser fixture tests run production scripts and CSS with simulated Chrome APIs. They are not a substitute for installed-extension verification on the live service. Before store submission, load the 1.3.10 staging directory in Chrome, disable any duplicate installation, refresh ChatGPT, and check an uploaded image, all built-in backgrounds, home-screen suggestions, a new answer, Paper/Low Vision presets, and background removal. Repeat on a fresh tab to verify persistence.

No new extension permissions or wider site access are requested. The corrected store description must remain free of the previously rejected domain list.
